Scenario map

Depositors each invest one unit in the bank. In period 2, the bank will get a return on investments. In period 1, some unlucky depositors privately learns they are type 1 and must withdraw early. The bank provides an additional return as a form of insurance against being a type 1 investor. In period 2, type 2 investors withdraw their deposits plus returns. But if everyone panics and withdraws at once… …the bank can run dry before everyone is paid. A guarantee to honor deposits removes the reason to panic.

Definitions

Type 1

Investors who must unexpectedly pull investment before returns.

Type 2

Investors who wait for return.

r₁

Fixed claim per unit paid to anyone withdrawing early (period 1); r₁ > 1.

R

Gross return per unit if the investment matures to period 2; R > r₁.

Theory

Setup (T = 0, 1, 2). One unit invested yields the technology

−1  →  { 1 if stopped at T=1 ;   R if held to T=2 }

so early liquidation returns only the principal, while patience earns R > 1.

Key assumption: all agents are identical at T=0 and only privately learn their type at T=1. A fraction t turn out to be Type 1. Because the type shock is unobservable, deposits provide liquidity insurance that a market in claims cannot.

Take a moment to see the two groups form — everything that follows is about how the bank splits its pooled funds between them.

Demand-deposit contract: a withdrawal at T=1 pays a fixed claim r₁ per unit, with 1 < r₁ < R. Payment per unit deposited is

V₁(fj, r₁) = r₁ if fj < 1/r₁, else 0 eq (2)

Only Type 1 withdraw (the good equilibrium). They deposited 25 but are owed r₁·25 = 37.5.

Where the extra comes from: R is not realized yet, so the bank liquidates part of the long investment early (each unit back to principal, 1). Type 1’s own 25 covers only part — the remaining 12.5 is drawn from Type 2’s stake. This cross-subsidy is exactly the liquidity insurance the demand deposit provides.

A depositor who waits to T=2 receives, per unit,

V₂(f, r₁) = max{ R(1 − r₁f)/(1 − f), 0 } eq (3)

With only Type 1 withdrawing (f = t = ¼), V₂ > r₁, so Type 2 strictly prefer to wait. The 62.5 left invested matures to 62.5 × R = 125 for Type 2.

This is the good equilibrium — it achieves optimal risk sharing across the two types.

Bank run. Withdrawing at T=1 is only safe if you expect others to wait. If enough depositors expect a run, withdrawing immediately becomes each agent's best response — a second, self-fulfilling Nash equilibrium alongside the good one.

Sequential service. V₁(fj, r₁) = r₁ if fj < 1/r₁, else 0 (eq. 2) — position in line, not type, decides who is paid in full and who gets nothing once the bank exhausts its assets.

Deposit insurance (§V) guarantees the promised payout regardless of how many withdraw, so it is never profitable to join a run — the good equilibrium becomes the unique equilibrium.
